# LRO_EXAMPLE Project

## Команды перед запуском проекта

Перед запуском проекта необходимо активировать виртуальное окружение:

```bash
source ~/.pyenv/activate
pyenv activate lro_venv
```

## Установка пакетов

Все пакеты устанавливаются через `python -m pip install`:

```bash
python -m pip install some_package
```
